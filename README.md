# Forma company website

Open `dist/index.html` in any modern browser. No installation or build required.

Includes responsive navigation, hero, three services, approach, email contact, and footer. The email link opens the visitor's email application.

Forma is a sample brand. Replace `hello@forma.example`, company name, and copyright details with real company information before public use. No contact form or backend is included. Google Fonts are optional; system fonts work offline.
